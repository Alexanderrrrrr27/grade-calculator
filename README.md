
# Student Grade Calculator

**Name:** Maui Alexander Tangarorang

**Section:** IT3R4

## Description

This is a simple Python program that calculates
the average grade of a student based on Prelim,
Midterm, and Finals grades.

It also displays the student's average and
corresponding rating.

## How to Run

1. Install Python on your computer.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Type the following command:

python grade_calculator.py

5. Enter the student name and grades.
6. The program will display the average and rating.

## Programming Language

Python
